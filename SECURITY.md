# Reporting a vulnerability

Email [state303@dsub.io](mailto:state303@dsub.io) with the affected version,
a description of the issue, and reproduction steps. Include relevant logs with
credentials and private data removed. Report details privately before opening
a public issue.

Use the current [release](https://github.com/dsub-io/go-open-discogs-batch/releases)
when checking whether a problem still exists. This repository does not publish
a separate long-term support schedule for older versions.
